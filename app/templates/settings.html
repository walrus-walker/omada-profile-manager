Where Omada API Credentials Come From

This app connects to your existing Omada Controller using the Omada Open API. You do not create the API — Omada already has it. You register an API application inside the Omada web UI so this app can authenticate.

  1. Log in to the Omada Controller web UI
  2. Switch to Global View (top-left dropdown)
  3. Go to Settings → Platform Integration → Open API
  4. Click Add to create a new Open API application
  5. Select Client mode when prompted
  6. Copy the generated Client ID, Client Secret, and Omada ID
  7. Re-run ./scripts/setup.sh and enter those values when prompted
